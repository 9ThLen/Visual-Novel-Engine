# Налаштування програми

[Опис проєкту](README.md) · [Встановлення](INSTALLATION.md) · [Посібник користувача](USER_GUIDE.md) · [English](../en/SETTINGS.md)

Відкрийте налаштування програми, щоб змінити мову, звук і параметри читання. Почніть зі стандартних значень і змінюйте те, що впливає на ваш комфорт. У дужках наведені англійські назви для орієнтування в англійському інтерфейсі.

| Налаштування | На що впливає та коли його змінювати |
| --- | --- |
| Мова (Language) | Перемикає інтерфейс між українською та англійською. Не перекладає текст історії. |
| Музика (Music) | Змінює гучність фонової музики. Зменште її, якщо вона заважає сприймати діалог або оповідь. |
| Голос (Voice) | Змінює гучність голосових записів. Не створює озвучення. |
| Ефекти (Effects) | Змінює гучність звукових ефектів окремо від музики й голосу. |
| Швидкість тексту (Text speed) | Визначає швидкість появи тексту. Підлаштуйте її під свій темп читання. |
| Розмір тексту (Text Size) | Змінює розмір тексту в діалоговій панелі. |
| Шрифт читача (Reader font) | Змінює масштаб шрифту в читачі. Збільште його, якщо довгі уривки важко читати. |
| Міжрядковий інтервал (Line spacing) | Змінює відстань між рядками в читачі. Збільште її, якщо текст здається надто щільним. |
| Автовідтворення (Auto-play) | Вмикає автоматичне просування під час читання. Вибори все одно потребують рішення читача. |
| Паралакс (Parallax) | Вмикає ефект руху шарів. Вимкніть його, якщо вам зручніше читати зі стабільним зображенням. |
| Фонове відео (Background video) | Керує відтворенням відеофонів. Вимкніть, якщо не хочете рухомого відео на тлі. |
| Сховище (Storage) | Показує відомості про сховище, якщо браузер це підтримує, та може запропонувати запит постійного зберігання. Воно не замінює резервну копію й не захищає від ручного очищення даних сайту. |
| Хмарне резервування (Cloud backup) | Дає доступ до додаткового хмарного збереження та входу. Потребує налаштованого сервісу. |

## Локальне сховище та резервні копії

Історії прив’язані до поточного профілю браузера й адреси сайту. Інший браузер має окремі дані, а приватний режим може видалити їх після завершення сеансу.

Повна резервна копія зі сторінки проєкту зберігає історію та медіафайли в одному переносному файлі. JSON-експорт не містить медіа. Перед зміною браузера чи комп’ютера пройдіть [крок про резервні копії](USER_GUIDE.md#7-збережіть-повну-копію).

## Додаткове хмарне налаштування

Якщо ви запускаєте власну копію з вихідного коду, доступні параметри середовища описані в [`.env.example`](../../.env.example). Копіюйте його до `.env` лише коли налаштовуєте додаткову інтеграцію. Для хмарного резервування використовуються `EXPO_PUBLIC_SUPABASE_URL` та `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY`. Після їх зміни перезапустіть сервер розробки.

Не розміщуйте ключ Supabase `service_role` у конфігурації браузера та не додавайте облікові дані до Git. Після налаштування сервісу увійдіть через елементи хмарного резервування в програмі й перевірте його стан. Сам запуск локальної програми не вмикає хмарні копії.

## Додатковий AI-помічник

Параметри AI-провайдера відокремлені від налаштувань читання. Вибраний провайдер і спосіб підключення визначають потрібні облікові дані та доступні можливості. [Інструкція AI bridge англійською](../../tools/ai-bridge/README.md) описує провайдерів і локальне сполучення. Використання провайдера може потребувати платного облікового запису або оплачуватися окремо.
