## Project and developer references

- [Technical wiki](../wiki/index.md) covers architecture, runtime, packaging, and testing.

Plans and reviews describe their recorded scope and date; they are not substitutes for current user instructions. A document's presence here does not mean every planned feature is complete or every old finding still applies.
